Possible duplicates and overlaps (none proposed for closing):

- **#522 / #573** (`actions.deploy_python_fastapi`). #573 asks to remove the function, and #522 asks to make its ignored `conda_mode` argument optional. Removing it (#573) would settle #522 too. Keep both for now: they are different fixes, and the code currently calls the function "a supported shim; keep these signatures stable" for vetiver (`rsconnect/actions.py:322-327`). If the maintainers choose removal, close #522 as a duplicate of #573, which has the migration plan.
- **#371 / #720** (file exclusion). #720 is a concrete `--exclude` bug, and #371 asks for a `.connectignore` file with gitignore semantics, which would replace the custom glob matcher. They are related but not duplicates. Fixing #720 should not wait for #371.
- **#829 / #831** (Posit Publisher `.posit/`). #831 is a follow-up that depends on #830 (open PR for #829). Not duplicates.
- **#702** (`deploy static`) is related to #611 / #548 (no `write-manifest html`), which the manifest batch covers. Not duplicates.
- **#382** may have the same root cause as #414: a symlinked file is hashed through to its target for the manifest but stored as a symlink in the tarball, so the checksums disagree.
