# Triage Labels

Labels used to track an issue's triage state on GitHub. Use these exact strings; don't create variants.

| Label             | Meaning                                                     |
| ----------------- | ----------------------------------------------------------- |
| `needs-triage`    | A maintainer needs to evaluate this issue                   |
| `needs-info`      | Waiting on the reporter for more information                |
| `ready-for-agent` | Fully specified; a coding agent can implement it unattended |
| `ready-for-human` | Specified, but needs a human to implement it                |
| `wontfix`         | Will not be actioned                                        |
